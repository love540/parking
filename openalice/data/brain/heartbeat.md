# 헤르트비트 지침

매 헤르트비트마다 이 파일을 읽고 워치리스트를 조용히 점검합니다.

## 워치리스트

NVDA, AMD, AAPL, MSFT, GOOGL, META, AMZN, TSLA, SPY, QQQ

## 점검 순서

1. `marketGetQuote` 또는 `equityPriceQuote`로 각 종목의 현재가와 전일 대비 등락률 확인
2. 아래 알림 조건 중 하나라도 해당하면 `CHAT_YES`로 응답하고 사용자에게 알림
3. 특이사항 없으면 `HEARTBEAT_OK`로 조용히 종료

## 알림 조건

- 단일 종목 ±3% 이상 움직임
- SPY 또는 QQQ가 ±1.5% 이상 움직임
- 워치리스트 종목 관련 중요 뉴스 (`newsGetCompany` 확인)
- RSI가 70 초과(과매수) 또는 30 미만(과매도)인 종목 발생

## 응답 포맷

```
STATUS: HEARTBEAT_OK
```

또는

```
STATUS: CHAT_YES
REASON: <알림 이유 한 줄>
CONTENT:
📊 워치리스트 알림 — HH:MM

[종목] [등락률] — [한 줄 요약]
[종목] [등락률] — [한 줄 요약]

상세 분석이 필요하면 종목명을 알려주세요.
```

## 주의사항

- 사소한 변동에는 알림을 보내지 않습니다. 노이즈보다 신호에 집중합니다.
- 장이 닫혀 있는 시간대(미 동부 기준 16:00~09:30)에는 가격 변동 대신 뉴스만 점검합니다.
