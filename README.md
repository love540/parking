# 🅿️ 주차 할인권 계산기 (Parking Ticket Calculator)

모바일 환경에서 주차시간을 입력하면 **필요한 할인권 개수**, **남은 무료시간**, 또는 **초과 주차요금**을 계산해주는 간단한 웹앱입니다.  
방문권 1개와 할인권 최대 5개까지 적용 규칙을 기반으로 동작합니다.

---

## 🚗 주요 기능

| 기능 | 설명 |
|------|------|
| **시간/분 입력** | 사용자가 주차시간을 `시간 + 분` 단위로 직접 입력 (0~5시간, 0~59분) |
| **자동 계산 버튼 활성화** | 입력이 유효하면 ‘계산하기’ 버튼이 활성화됨 |
| **방문권 자동 적용** | 방문권 1개(90분 무료)는 항상 기본으로 적용됨 |
| **할인권 계산** | 1개당 30분 무료, **최대 5개까지만 적용** |
| **남은 시간 또는 초과 요금 표시** | 무료 시간이 남으면 `남은 시간(분)` 표시, 초과 시 `초과 주차요금(원)` 표시 |
| **초과 요금 계산 규칙** | 초과 시간에 대해 **15분당 1,000원** (올림 적용) |
| **리셋 기능** | 결과 표시 후 ‘리셋’ 버튼으로 초기 상태 복귀 |

---

## ⚙️ 계산 규칙

### 1️⃣ 기본 무료시간
- 방문권 1개 = **90분 무료**

### 2️⃣ 할인권
- 할인권 1개 = **30분 무료**
- **최대 5개까지만 적용 가능**

### 3️⃣ 초과 요금 계산
| 초과 시간(분) | 청구 요금(원) |
|----------------|----------------|
| 1~15분 | 1,000원 |
| 16~30분 | 2,000원 |
| 31~45분 | 3,000원 |
| 46~60분 | 4,000원 |
| ... | 15분 단위로 1,000원씩 증가 |
