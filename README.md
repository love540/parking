# 🅿️ 주차 할인권 계산기 (Parking Coupon Calculator)

이 프로젝트는 모바일 환경에서 간단하게 사용할 수 있는 **주차 할인권 계산 웹페이지**입니다.  
방문권(100분 무료)과 할인권(30분 무료)을 적용하여 **최소 필요 할인권 개수와 남는 무료 시간**을 계산해줍니다.

---

## 🚀 기능

- **입력**
  - 주차시간을 **시간(0~5)** 과 **분(0~59)** 으로 입력
  - 기본 placeholder: `0시 00분`
- **출력**
  - 필요한 할인권 개수
  - 남은 시간(무료분)
- **방문권**
  - 기본 1개(100분 무료) 자동 적용
- **UI 동작**
  - `계산하기` 버튼 → 결과 표시
  - `리셋` 버튼 → 초기화

---

## 📱 실행 방법

1. 소스 코드(`parking.html`)를 다운로드합니다.
2. 모바일/PC 브라우저에서 열 수 있습니다.

### iPhone (iOS Safari)
- `파일` 앱에서 `parking.html`을 **길게 누른 후 → 공유 → Safari로 열기**
- Safari에서 열리면, **공유 버튼 → 홈 화면에 추가** 를 통해 앱처럼 사용할 수 있습니다.

### Android (Chrome)
- `내 파일` 앱에서 `parking.html`을 **Chrome으로 열기**
- Chrome 메뉴(⋮) → **홈 화면에 추가**
